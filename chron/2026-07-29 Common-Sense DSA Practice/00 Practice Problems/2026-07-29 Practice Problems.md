## Suggested Learning Path

```
Arrays/Binary Search → Big O intuition → Hash Tables
       ↓
Stacks/Queues → Recursion → Sorting
       ↓
Linked Lists → BSTs → Heaps → Tries → Graphs → DP
```

**Platform guidance:**
- **CSES** — Clean statements, progressive difficulty, great for structured learning
- **LeetCode** — Best editorial quality, interview-focused
- **HackerRank** — Good for topic-focused drill sets with guided hints
- **Kattis** — Problems rated by difficulty (0–10); excellent for calibrating skill level; use [difficulty filter](https://open.kattis.com/problems?order=difficulty_category) to start easy
- **UVa** — Classic academic problems; use [uHunt](https://uhunt.onlinejudge.org/) to browse by category and track progress
- **Codeforces / SPOJ / CodeChef** — Extra challenge once comfortable with a topic
